Transcode via GitHub

Uploads the current recording to docs/uploads/, triggers the self-hosted runner workflow, and dispatches one DCP slice that runs the browser dcpGhRunner package (JIT register → transcode → LinkedIn). Requires a token with repo and workflow scopes.

LinkedIn (optional — direct API)

When both token and author URN are set, the worker posts via LinkedIn REST. Otherwise it commits the MP4 + metadata JSON and triggers post-to-linkedin.yml.

Token is cached in this browser only (localStorage).
